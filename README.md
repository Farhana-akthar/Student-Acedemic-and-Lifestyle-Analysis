# Student Academic and Lifestyle Analysis

## Overview
This project performs **Exploratory Data Analysis (EDA)** on a dataset of students to analyze the relationship between **academic performance (GPA)** and various lifestyle factors such as study hours, sleep hours, attendance, social media usage, and extracurricular activities.

The goal is to identify patterns and insights that show how different habits and behaviors impact student performance.

---

## Dataset
- File: `students.csv`
- Contains student data with the following columns:
  - `Student_ID` – Unique ID for each student
  - `Age` – Age of the student
  - `Gender` – Male/Female
  - `Study_Hours` – Average daily study hours
  - `Sleep_Hours` – Average daily sleep hours
  - `Attendance` – Percentage attendance
  - `GPA` – Academic performance
  - `Extracurricular` – Participation in activities (Yes/No)
  - `Internet_Usage` – Daily internet usage in hours
  - `Social_Media_Hours` – Daily social media usage in hours

---

## Features
- Data cleaning and preprocessing using **pandas**.
- Visualizations using **matplotlib** and **seaborn**:
  - GPA distribution
  - Study hours vs GPA
  - Attendance vs GPA
  - Social media usage vs GPA
  - Correlation heatmap
  - Boxplots for extracurricular activities
- Insights and analysis of patterns affecting GPA.
